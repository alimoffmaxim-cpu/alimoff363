# Правка лендинга «Электромото Зеленоград»

Факты, утверждённые решения и отказы заказчика — в `gluhov-moto-landing/CLAUDE.md`. Прочитай его перед правкой; не предлагай то, что в разделе «Отклонено».

## Правила общения
- Заказчик пишет по-русски, коротко, со скриншотами. Отвечать по-русски, просто, без жаргона.
- **Менять ровно то, что попросили.** Заметил ещё проблему — предложи отдельно, не исправляй молча (был откат из-за «лишней» правки).
- Если запрос — выбор формулировки или вид («предложи варианты», «покажи сначала») — сначала текст/макет со скриншотом, правка только после «ок». Если просьба прямая («замени X на Y») — делай и показывай скриншот.
- Визуальные идеи, которые уже отклонены (фото в карточках классов, векторные и MakeHuman-люди, Blender-иконки кроме шлема, рюкзак/щит/каска), не возвращать.

## Где править
Только `gluhov-moto-landing/landing.html` (+ `legal/*.html` для юр. страниц, `tools/tilda-form.css` для вида формы Тильды). Всё остальное генерируется.

## После каждой правки (из папки `gluhov-moto-landing`)
```bash
python3 tools/make_example.py                 # tilda-example.html (демо-форма)
python3 tools/build_tilda.py                  # tilda/1..5-*.html, preview.html, copy.html
python3 tools/make_preview.py <scratchpad>/preview   # папка превью для артефакта
node tools/shot.js tilda/preview.html '<селектор>' <scratchpad>/x 1440,390   # проверка, scrollWidth = ширине
```
Затем:
1. Перепубликовать **те же** артефакты (не создавать новые):
   - превью: `Artifact` file_path=`<scratchpad>/preview/index.html` → https://claude.ai/artifact/8R8jMkRNuTic4txxohGfEn (если менялись media/legal — передать их в `files`; перед перезаписью чужих версий файла — `action: list, scope: files`);
   - код для Тильды: скопировать `tilda/copy.html` в scratchpad и опубликовать → https://claude.ai/artifact/QfKUZjt4tjLomArK9jvSt3.
   В новой сессии без истории: публикация с `url` требует сначала `action: "read"`.
2. Коммит (сообщение «Moto landing: …») и `git push -u origin <ветка>`.
3. Показать скриншот (SendUserFile) и обе ссылки.

## Ловушки
- `sed` с `&` в замене вставляет найденный текст — для HTML-замен используй Python `str.replace` с `assert s.count(a) == 1`.
- Контурный шрифт Unbounded (`-webkit-text-stroke`) даёт лишние линии внутри букв — известно, заказчику предложено сделать сплошным.
- Не вешать `gm-reveal` на iframe карты — виджет Яндекса рисуется узкой полоской.
- `MEDIA_BASE` закреплён на хеше коммита jsDelivr: заменил файлы в `media/` → см. навык `moto-media-optimize`.
- В Playwright Chromium нет H.264: mp4 не играют, на скриншотах видна обложка — это норма.
- Иконки (Fluent 3D, шлем) встроены data:webp прямо в HTML — заменять строку целиком через Python.
- Никаких телефонов, мессенджеров, соцсетей — только форма (CLAUDE.md, «Связь только через форму»).
