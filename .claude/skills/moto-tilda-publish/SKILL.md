# Выгрузка в Тильду

Полная пошаговая инструкция с таблицей полей формы — `gluhov-moto-landing/CLAUDE.md`, раздел «Выгрузка в Tilda». Готовые коды с кнопками «Скопировать» — https://claude.ai/artifact/QfKUZjt4tjLomArK9jvSt3 (собирается `tools/build_tilda.py` в `tilda/copy.html`). Общий порядок работы в Тильде через Chrome — навык `tilda-landing` (`references/tilda-chrome.md`), если он доступен.

## Если браузера нет
Облачная сессия не видит Chrome пользователя, даже если расширение установлено. Скажи это одной фразой и предложи: Claude Desktop с Claude in Chrome (новый разговор, папка репозитория) или `claude remote-control` на его компьютере. Не обещай публикацию, которую не можешь сделать.

## Порядок (с браузером)
1. Пользователь сам входит в Тильду и показывает проект. Адрес лендинга — `/moto-zelenograd` (уточнить).
2. Перед вставкой: `python3 tools/build_tilda.py` из `gluhov-moto-landing`, чтобы блоки были свежими.
3. Страница: T123 (`tilda/1-t123-main.html`) → BF204N (настройки из CLAUDE.md: класс `gm-signup`, якорь `signup`, галочка согласия **не отмечена**, лейбл со ссылками) → T123 (`tilda/3-t123-footer.html`). После каждой вставки сверить длину `ace_editor…getValue().length` с файлом.
4. Приём данных: **только Tilda CRM и почта (российский сервис)**. Telegram, Google Таблицу — не подключать. В «Настройках сайта» не должно быть виджетов мессенджеров/обратного звонка и подключённой Метрики.
5. Страницы `/privacy-moto` и `/consent-moto` (`tilda/4-…`, `tilda/5-…`, фон `#0d0f13`). С жёлтыми заглушками оператора — только с явного согласия пользователя (см. `moto-legal-152fz`).
6. **Публикация и тестовая заявка — только после явного «да» пользователя.** Тестовую заявку «ТЕСТ» удалить после проверки.

## Проверка живой страницы (по ссылке, можно и из облака)
```bash
U='https://<домен>/moto-zelenograd?v=2'
curl -sL "$U" -o /tmp/live.html
grep -c 'uc-gm-signup\|gm-cookie\|gmConfig' /tmp/live.html          # блоки и форма на месте
grep -o 'name="Checkbox"[^>]*>' /tmp/live.html                        # без checked
grep -niE 't\.me/|wa\.me|whatsapp|instagram\.com|tel:' /tmp/live.html # должно быть пусто
grep -c 'mc.yandex.ru/metrika' /tmp/live.html                         # 0: Метрику включает наш код после согласия
for p in privacy-moto consent-moto; do curl -s -o /dev/null -w "%{http_code} $p\n" "https://<домен>/$p"; done
```
Медиа: каждый файл из `CONFIG.MEDIA` по `MEDIA_BASE` отвечает 200. Скриншоты живой страницы — `node tools/shot.js` не годится для URL; открыть URL в Playwright напрямую (1440 и 390). Отчитаться: что работает, что поправить в редакторе.
