## Google Apps Script: установка кода (во всех проектах по умолчанию)

Код ставят копированием в редактор Apps Script, поэтому раздел установки в README каждого проекта
пишется так, как в `moto-dashboard`:

- **Не просить вставлять весь код в один `Код.gs`**: редактор обрезает длинную вставку
  (`SyntaxError: Unexpected identifier`). Каждый `.gs` из репозитория — отдельный файл в редакторе:
  **Файлы → + → Скрипт**, имя без `.gs`, в него — код одноимённого файла. `Код.gs` удалить или очистить.
- Для каждого файла — ссылка на raw-страницу, чтобы копировать Cmd+A → Cmd+C:
  `https://raw.githubusercontent.com/alimoffmaxim-cpu/alimoff363/<ветка>/<папка>/<файл>.gs`.
  Ветка — та, куда запушен код. Ссылки обновлять, когда меняется ветка или список файлов.
- **Порядок файлов не должен иметь значения**: Apps Script загружает файлы в порядке создания.
  На верхнем уровне файла — только литералы; константы, которые зависят от констант из других
  файлов, вычислять в функциях или геттерах.
- Файлы держать примерно до 100–150 строк.
- Секретов в коде нет: ключи и токены — только в Свойствах скрипта, вводятся через меню.
