## Шар судьбы

| Что | Где | Опубликовано |
|---|---|---|
| Шар с пацанскими ответами | `shar-sudby/index.html` | https://claude.ai/artifact/6xYwomsLNMtiiSJp4cBKGM |
| Классический шар, 26 языков | `shar-sudby-classic/index.html` | https://claude.ai/artifact/RkBUta1LSj84AS1fZSDfK5 |
| Сайт для поисковиков (страница на каждый язык) | исходники в `magic-8-ball/`, готовый сайт в `docs/` | GitHub Pages: ветка `claude/clever-ptolemy-y6ksun`, папка `/docs` |

Сайт собирается командой `python3 magic-8-ball/build.py`.
Тексты и переводы лежат в `magic-8-ball/langs.json`.
Под свой домен: `python3 magic-8-ball/build.py --base https://домен/`.

Что осталось сделать: купить домен (выбрали shakethe8ball.com или .site), подключить его к GitHub Pages,
добавить сайт в Google Search Console и Яндекс Вебмастер.
