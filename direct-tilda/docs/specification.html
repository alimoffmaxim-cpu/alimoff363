Приложение «direct to sheets»: выгрузка статистики Директа в Google Таблицы

Владелец: аккаунт alimov-partners (агентство, работа с кабинетами клиентов). Только чтение данных — кампании не создаются и не изменяются.

1. Назначение

Ежедневный отчёт для клиентов агентства в Google Таблице: расход, показы и клики из Яндекс Директа с разбивкой по кампаниям, группам и объявлениям, сведённые с реальными заявками с сайта клиента (Тильда). Заявки сопоставляются с кампанией, группой и объявлением по UTM-меткам — видна фактическая цена заявки по каждому объявлению.

2. Схема взаимодействия

Триггер Google Apps Script1 раз в сутки (01:00 МСК) или вручную из меню таблицы
→
API Директа v5 (JSON)OAuth-токен агентства + заголовок Client-Login кабинета клиента
→
Google Таблицалист «Данные Директа»: 1 строка = день × объявление; листы отчёта за период
←
Заявки с сайтавебхук Тильды (не связан с API Директа)
