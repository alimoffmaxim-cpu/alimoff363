# WordFlow — карточки для изучения английского на iPhone

Приложение в духе Anki: слова показываются по алгоритму интервальных повторений (SM-2),
поэтому вы повторяете слово именно тогда, когда начинаете его забывать.
Это PWA — оно ставится на iPhone из Safari и работает без интернета.

## Возможности

- **Интервальные повторения как в Anki**: этапы «новое → изучаемое → повторение», кнопки
  «Снова / Трудно / Хорошо / Легко» с подсказкой, когда карточка вернётся.
- **Встроенные колоды** (≈280 слов и фраз): базовые слова A1, повседневные слова A2,
  частые глаголы с формами, фразовые глаголы, разговорные фразы. У каждого слова —
  транскрипция, перевод и пример.
- **Два направления**: EN → RU и RU → EN (или оба). Вторая сторона того же слова в
  тот же день не показывается.
- **Озвучка** английских слов и примеров голосом iPhone, автоматически или по кнопке 🔊.
- **Статистика**: серия дней подряд, ответы и точность за сегодня, состав коллекции,
  прогноз повторений на неделю, активность за 30 дней.
- Отмена последнего ответа (↶), лимиты новых слов и повторений в день, тёмная тема.
- Работает офлайн, прогресс хранится на устройстве.

## Как установить на iPhone

1. Опубликуйте приложение (см. ниже) и откройте ссылку **в Safari**.
2. Нажмите «Поделиться» → **«На экран Домой»** → «Добавить».
3. Запускайте WordFlow с домашнего экрана — оно откроется на весь экран, как обычное
   приложение, и будет работать без интернета.

> Устанавливайте именно на экран «Домой»: так iOS не удалит ваш прогресс.

## Публикация через GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`. Чтобы он заработал:

1. GitHub → репозиторий → **Settings → Pages** → в «Source» выберите **GitHub Actions**.
2. Слейте изменения в ветку `main` (или запустите workflow вручную во вкладке Actions).
3. Адрес появится в Settings → Pages, обычно `https://<ваш-логин>.github.io/<репозиторий>/`.

GitHub Pages для приватных репозиториев доступен только на платных тарифах — в этом
случае сделайте репозиторий публичным или разместите папку `english-srs/` на любом
статическом хостинге (Netlify, Cloudflare Pages, Vercel).

## Запуск на компьютере

```bash
cd english-srs
npm start        # http://localhost:8080
npm test         # тесты алгоритма повторений
```

## Как добавить слова

Слова лежат в `data/decks.js` в формате `[английский, транскрипция, перевод, пример]`.
Добавляйте новые слова или колоды и увеличьте `VERSION` в `sw.js`, чтобы iPhone
загрузил обновление. Не переименовывайте `id` колод и уже изучаемые слова —
по ним хранится прогресс.
