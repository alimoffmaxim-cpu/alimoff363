# Личный финансовый бот для Telegram

Бот для учёта личных доходов, расходов и балансов счетов с дашбордом:
доходы и расходы за месяц, динамика к прошлому месяцу, график за 6 месяцев,
структура расходов по категориям.

Главный принцип — **данные видите только вы**, и даже при утечке файла базы
или взломе сервера прочитать их без вашего PIN практически невозможно.

## Как устроена защита

| Угроза | Защита |
|---|---|
| Чужой человек нашёл бота и пишет ему | Бот отвечает **только** на ваш Telegram ID (`OWNER_ID`). Остальным — полная тишина, вам приходит уведомление о попытке. Из групп бот сразу выходит. |
| Кто-то взял ваш разблокированный телефон / угнал сессию Telegram | Доступ к данным — только после ввода PIN. Сообщение с PIN удаляется сразу. После 15 минут бездействия бот блокируется сам. |
| Перебор PIN | 5 ошибок → пауза 15 мин, дальше 30 мин, 1 ч, 2 ч… Счётчик хранится в базе и не сбрасывается перезапуском. |
| Переписка с цифрами висит в чате | Все сообщения с данными (ваши и бота) удаляются через 10 минут и сразу при `/lock` или авто-блокировке. Сообщения бота защищены от пересылки и сохранения (`protect_content`). |
| Утёк файл базы (бэкап, копия диска) | Каждая запись зашифрована **AES-256-GCM**. В файле нет ни одной суммы, категории, даты или названия счёта в открытом виде. |
| Взломан сервер (украли и базу, и `.env`) | Ключ шифрования = `HKDF(MASTER_KEY + scrypt(PIN))`. Без PIN ключа нет даже у владельца сервера; каждая попытка подбора стоит ~64 МБ памяти и ~0,2 с. Используйте длинный PIN/пароль — это главная линия обороны. |
| Утечка токенов через репозиторий | Секреты хранятся только в `.env` на сервере (`chmod 600`, бот откажется запускаться с открытым файлом). `.env` и база — в `.gitignore`. В коде нет ни одного секрета. |
| Бот открывает порт наружу | Нет: используется long polling, серверу не нужен публичный адрес. |

**Честно об ограничениях.** Переписка с ботом в Telegram не имеет сквозного
шифрования — сообщения проходят через серверы Telegram (поэтому бот их и удаляет).
Пока бот разблокирован, ключ находится в памяти процесса. Если PIN забыт —
данные восстановить нельзя, это плата за стойкость.

## Установка

Все секреты вы создаёте и вводите **сами, на своём сервере**.
Не отправляйте токен бота, мастер-ключ или PIN никому — ни в чаты, ни ИИ-ассистентам,
ни в issues/коммиты. Этот репозиторий публичный: храните в нём только код.

### 1. Создайте бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`, получите токен.
2. Там же: `/setjoingroups` → выберите бота → **Disable** (бота нельзя будет добавить в группу).
3. Узнайте свой числовой ID у [@userinfobot](https://t.me/userinfobot).
4. Включите облачный пароль в Telegram: *Настройки → Конфиденциальность → Облачный пароль*.
   Это защищает сам аккаунт, через который вы входите в бот.

### Быстрый запуск на своём Mac/Linux (для проверки)

```bash
cd путь/к/finance-bot
bash start.sh
```

Скрипт поставит зависимости, скрыто спросит токен и ваш ID, сам сгенерирует
мастер-ключ, сохранит всё в `.env` (права 600) и запустит бота. Повторный
запуск — та же команда. Бот работает, пока открыт терминал и компьютер не спит.

### Сервер в Google Cloud одной командой (бесплатный e2-micro)

1. Создайте виртуальную машину: *Compute Engine → VM instances → Create instance*:
   регион **us-central1 / us-west1 / us-east1**, тип **e2-micro**,
   диск — **Ubuntu 24.04 LTS**, тип диска **Standard persistent disk**, до 30 ГБ.
2. Нажмите **SSH** напротив машины — откроется консоль в браузере. Вставьте:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/alimoffmaxim-cpu/alimoff363/claude/keen-hawking-q34ozn/finance-bot/deploy/install.sh | sudo bash
   ```

   Скрипт установит зависимости, спросит токен и ваш ID, создаст ключ шифрования и запустит бота
   как службу systemd (автозапуск после перезагрузки, изоляция, код доступен боту только на чтение).
   Повторный запуск той же команды обновляет бота, сохраняя `.env` и данные.
3. Остановите бота на Mac, если он там запущен: один бот не может работать в двух местах одновременно.

### 2. Разверните на сервере (Linux, Python 3.11+)

```bash
sudo useradd --system --home /opt/finbot --shell /usr/sbin/nologin finbot
sudo mkdir -p /opt/finbot && sudo chown finbot:finbot /opt/finbot
# скопируйте содержимое папки finance-bot в /opt/finbot, затем:
cd /opt/finbot
sudo -u finbot python3 -m venv .venv
sudo -u finbot .venv/bin/pip install -r requirements.txt
sudo -u finbot mkdir -m 700 data

sudo -u finbot cp .env.example .env
sudo chmod 600 .env
sudo -u finbot .venv/bin/python -m finbot genkey   # скопируйте вывод в MASTER_KEY
sudo -u finbot nano .env                            # впишите BOT_TOKEN, OWNER_ID, MASTER_KEY
```

### 3. Запустите как сервис

```bash
sudo cp deploy/finbot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now finbot
sudo systemctl status finbot
```

Напишите боту `/start` — он попросит придумать PIN (минимум 6 символов;
лучше фраза из нескольких слов).

### Резервная копия

Копируйте `data/finance.db` — файл зашифрован. **Отдельно** и надёжно (например,
в менеджере паролей) сохраните `MASTER_KEY`: без него и без PIN бэкап не расшифровать.
Никогда не храните ключ рядом с бэкапом базы.

## Пользование

Основная валюта — **тайский бат (฿)**. Рубли используются только при обмене.

**Кнопки внизу чата:** ➖ Расход · ➕ Доход · 💱 Обмен · 📊 Дашборд · 🧾 История · 💰 Баланс · 🔒 Заблокировать.
Нажали «➖ Расход» → ввели сумму → выбрали категорию кнопкой. Частые категории — первыми.

**Или одной строкой:**

| Ввод | Что делает |
|---|---|
| `-350`, `350`, `расход 350` | расход 350 ฿ — бот предложит выбрать категорию |
| `350 еда обед`, `расход 1200 такси` | расход сразу с категорией (такси → 🛵 Транспорт) и заметкой |
| `+50000`, `доход 50000 зп` | доход |
| `обмен 90000 - 30000`, `обмен 90к 30к` | отдали 90 000 ₽, получили 30 000 ฿ — бот посчитает курс |
| `баланс 12000 б` | поправить баланс, если он разошёлся с реальным |
| `-900 такси вчера`, `-500 еда 25.09` | операция задним числом |
| `/undo`, `/del 12` | удалить последнюю / операцию №12 (или кнопка «↩️ Отменить») |
| `/lock`, `/changepin`, `/reset` | заблокировать · сменить PIN · удалить все данные |

**Баланс** считается автоматически: доходы + баты от обменов − расходы.
**Дашборд:** доходы и расходы месяца с изменением к прошлому, расходы в рублях по курсу обмена,
сумма и курс обменов, баланс, график за 6 месяцев и расходы по категориям.

## Дашборд в виде мини-аппа

Кнопка «📊 Дашборд» присылает сводку и кнопку **«Открыть дашборд»**. Она открывает
интерактивную страницу внутри Telegram: баланс, доходы и расходы с изменением к прошлому месяцу,
обмены и динамика курса, категории и последние операции. Месяцы переключаются нажатием.

Как устроена защита:
- страница (`webapp/`) — только код, **без данных**; её можно хранить в открытом виде;
- бот передаёт цифры во фрагменте ссылки (после `#`). Браузер **никогда не отправляет фрагмент
  на сервер**, поэтому хостинг страницы (GitHub Pages) данных не видит;
- политика безопасности страницы (CSP) запрещает ей любые сетевые запросы и чужие скрипты —
  кроме официального скрипта Telegram. Даже теоретически страница не может никуда отправить данные;
- сообщение с кнопкой удаляется из чата вместе с остальными.

**Включение (один раз):** на GitHub откройте репозиторий → *Settings* → *Pages* →
*Build and deployment*: Source — **Deploy from a branch**, Branch — ветка с ботом, папка **/ (root)** → *Save*.
Через 1–2 минуты страница будет доступна по адресу из `WEBAPP_URL` в `.env`.
Если `WEBAPP_URL` пустой, дашборд приходит картинкой (картинку можно получить и командой `/dash_png`).

## Настройки `.env`

| Переменная | По умолчанию | |
|---|---|---|
| `SESSION_MINUTES` | 1 | авто-блокировка после бездействия: чат очищается, остаётся кнопка «▶️ Старт» |
| `AUTO_DELETE_MINUTES` | 1 | через сколько удалять сообщения с данными |
| `TIMEZONE` | Asia/Bangkok | часовой пояс для «сегодня» |
| `WEBAPP_URL` | адрес на GitHub Pages | страница мини-аппа; пусто — дашборд картинкой |
