# Лендинг «Электромото Зеленоград» (сайт «Глухов»)

Посадочная страница нового направления: тренировки детей на электромотоциклах. Главная цель — собирать заявки через свою лид-форму. Страница вставляется в Тильду одним блоком T123.

## Факты о направлении (подтверждены заказчиком)

- Закрытый двухуровневый картодром, картинг-центр ZelenoKART. Адрес по сайту zelenokart.ru: ТРЦ «Зеленопарк», Ржавки, Зеленоград. **Заказчиком пока не подтверждён.**
- Дети **4–12 лет** (раньше было 4–10, исправлено 27.10). Опытные спортсмены тоже могут тренироваться, в том числе в непогоду.
- Классы мотоциклов 50 и 65. На странице: 50 — «Для старта», 4–7 лет; 65 — «Для уверенных», 7–12 лет.
- Два уровня — это одна трасса, по ней ездят все. Нельзя писать «нижний для новичков, верхний для опытных».
- Расписание предварительное: среда и суббота, 09:00–11:00. Администратор: +7 915 277-91-21.
- Цены (27.10):
  - разовое занятие — 6 000 ₽;
  - абонемент на 4 занятия — 22 000 ₽ (5 500 ₽ за занятие);
  - абонемент на 8 занятий — 43 200 ₽ (5 400 ₽ за занятие).
  - Абонемент действует 2 месяца.
- Исходные фото и видео заказчика: https://disk.yandex.ru/d/CMeTPXP51OMJKg

## Как устроена страница

- Всё в одном блоке: CSS и JS инлайн, классы с префиксом `gm-`, корень `#gm`.
- Настройки в `CONFIG` в конце файла:
  - `SCRIPT_URL` — пока заглушка `…/XXXXXXXX/exec`;
  - `METRIKA_ID` — пока `0`, цель `lead_form_submit`;
  - `ADDRESS`;
  - `MEDIA_BASE` и `MEDIA` — ссылки на фото и видео.
- Форма:
  - поля: имя, телефон с маской +7, возраст 4–12 или «Опытный спортсмен», день (ср/сб/любой), согласие на ПДн;
  - отправляет UTM-метки и страницу, есть скрытое поле против ботов;
  - отправка в Apps Script с `mode: 'no-cors'`;
  - в `tilda-example.html` демо-режим: при заглушке `SCRIPT_URL` ничего не отправляет и показывает «Спасибо».
- Медиа сейчас грузятся с jsDelivr из этого репозитория по закреплённому коммиту (`MEDIA_BASE … @803dcd87a172`). Поэтому **репозиторий должен оставаться публичным**, иначе фото и видео на сайте пропадут.
- 3D-трасса — three.js r128 с cdnjs, подгружается лениво. Если WebGL нет, показывается SVG-схема.
- Тексты по ходу работы правились и в `landing.html`, и в `tilda-example.html`, и в копии для превью. Держать все три в синхроне.

## Утверждённые решения (не менять без запроса)

- Тёмная тема. Акцент — жёлтый `#FFD400`: заказчик попросил «более жёлтый» вместо салатового.
- Первый экран: фоновое видео, где дети едут на мотоциклах. Картинг здесь не подходит. На компьютере — горизонтальный композит (`hero.mp4`, справа чёткое видео, вокруг размытое), на телефоне — вертикальное `hero-m.mp4`.
- 3D-трасса:
  - один замкнутый маршрут: низ → подъём по рампе → второй уровень → спуск;
  - второй уровень — цельная плита;
  - ракурс фиксированный (`az = 0.66`), сцена не вращается сама, двигаются только райдеры, сцену можно повернуть мышью или пальцем;
  - финиш — чёрно-белая клетка, повёрнутая поперёк дороги;
  - подписи: «1 уровень», «2 уровень», «Подъём ↑», «Спуск ↓».
- Карточки классов «50» и «65» — 3D-рендеры мотоциклов **без райдера**: `bike-50.png` красный №3, `bike-65.png` синий №57.

## Выгрузка в Tilda (делается в сессии с Claude in Chrome)

Подготовлено по скиллу `tilda-landing`. Блоки собирает `python3 tools/build_tilda.py` из `landing.html` → папка `tilda/`:
- `1-t123-main.html` — шрифты, все стили (обёртка `.gm`), всё до формы, JS верхних секций;
- `3-t123-footer.html` — CSS формы Tilda (`tools/tilda-form.css`), «Как добраться» + FAQ + подвал, липкая кнопка, JS;
- `preview.html` — как блоки выглядят вместе (форма — разметка t678, как на живой Tilda);
- `copy.html` — страница копирования, опубликована: https://claude.ai/artifact/QfKUZjt4tjLomArK9jvSt3

Правки дизайна — только в `landing.html`, потом пересборка. `tilda-example.html` и `lead.gs` для этой схемы не нужны (они для варианта «одна HTML-форма + Apps Script»).

**Страница = T123 (блок 1) → BF204N (форма) → T123 (блок 3).** Форма — стандартная Tilda: HTML-форма в T123 в CRM не отправляет.

Шаги в Chrome (подробности и координаты — `references/tilda-chrome.md` скилла):
1. Пользователь сам входит в Tilda и показывает проект. Новая страница → «Пустая страница» → заголовок «Электромотоциклы для детей в Зеленограде», адрес `/moto-zelenograd` (уточнить у пользователя).
2. T123 → вставить `1-t123-main.html` → сверить длину `ace_editor…getValue().length` с файлом.
3. BF204N под ним. Шапка: «Запишите ребёнка на тренировку» / «Оставьте заявку — администратор перезвонит, подберёт группу и класс мотоцикла и ответит на все вопросы.» Поля:

   | Поле | Тип | Переменная | Обяз. |
   |---|---|---|---|
   | Имя родителя | Имя | `Name` | да |
   | Телефон | Телефон, маска RU | `Phone` | да |
   | Возраст ребёнка | Выпадающий список 4…12 + «Опытный спортсмен», подсказка «Выберите возраст» | `Age` | да |
   | Удобный день | Радио: Среда / Суббота / Любой | `Day` | нет |
   | Согласие | Галочка, отмечена по умолчанию, лейбл со ссылкой на политику | `Checkbox` | да |

   Кнопка «Отправить заявку →». Успех: «Спасибо! Администратор перезвонит вам в ближайшее время.» Настройки блока: отступы 0 (и 480), 12 колонок, фон `#0d0f13`, название формы «Электромото Зеленоград — запись», якорь `signup`, CSS Class Name `gm-signup` (без него форма останется стандартной).
4. T123 под формой → вставить `3-t123-footer.html` → сверить длину.
5. Приёмщики (решение заказчика): **Tilda CRM, Google Таблица, Telegram и/или Email**. Подключить в «Настройки сайта → Формы» (вход в Google и бот Telegram — делает пользователь), затем отметить в «Контент → Приём данных» блока формы. amoCRM не нужен.
6. Опубликовать — только с подтверждения пользователя. Проверять живую страницу с `?v=N`: редактор и «Предпросмотр» код T123 не выполняют. Проверить вид формы (тёмная карточка, жёлтая кнопка, дни-«пилюли», фон с фото), 3D-трассу, якорь «Записаться».
7. Тестовая заявка «ТЕСТ» — только с подтверждения; проверить «Заявки», Tilda CRM, таблицу, Telegram; удалить тест.

Медиа на этой схеме по-прежнему с jsDelivr. В Chrome-сессии их можно сразу загрузить в Тильду (см. «Не доделано», п. 1) и пересобрать блоки.

## Среда и инструменты

- Ветка: `claude/trusting-turing-vrdq0i`.
- После перезапуска облачной сессии иногда пропадает право на пуш (`could not read Username`). Лечится переподключением GitHub на https://claude.ai/connect-github. Коммиты при этом не теряются.
- Рендер мотоцикла: `blender -b -P tools/render_bike.py -- '#e8312a' '#1e5bff' '#ffd400' 3 out.png 128`. Аргументы: цвет пластика, два служебных цвета, номер, файл, сэмплы. Фон прозрачный, Cycles CPU. Для синего: `'#1e5bff' '#e8312a' '#ffd400' 57`.
- Видео сжимались ffmpeg: H.264, `crf 29–30`, без звука, `+faststart`. Ролики 540×960, первый экран 1280×720. Картинки — до 1400 px, JPEG q76.
