# Лендинг «Электромотоциклы в Зеленограде» с лид-формой

Страница нового направления для сайта на Тильде: закрытый двухуровневый картодром,
электромотоциклы классов 50 и 65, дети 4–10 лет, тренировки по средам и субботам.

Заявка из формы сразу попадает:
- в **Google Таблицу** (лист `Заявки`, с UTM-метками и страницей);
- в **Telegram** (бот пишет в чат администратора);
- на **почту**;
- в **CRM** — пока заглушка `sendToCrm_` в `lead.gs`, добавим, когда появится amoCRM/Bitrix24.

Файлы:
- [`landing.html`](landing.html) — вся страница одним куском для блока T123 в Тильде;
- [`lead.gs`](lead.gs) — Google Apps Script, который принимает заявки. Сервер не нужен.

## 1. Таблица и скрипт

1. Создайте Google Таблицу «Заявки — мотоциклы Зеленоград» → **Расширения → Apps Script**.
2. Замените содержимое `Код.gs` на [`lead.gs`](lead.gs), сохраните.
3. **Настройки проекта → Свойства скрипта** — добавьте нужные каналы (любой можно пропустить):

   | Свойство | Значение |
   |---|---|
   | `TG_BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
   | `TG_CHAT_ID` | ID чата: добавьте бота в группу админов, напишите в ней что-нибудь и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там `chat.id` |
   | `NOTIFY_EMAIL` | почта для заявок, можно несколько через запятую |

4. В редакторе выберите функцию `testLead` → **Выполнить** (Google попросит разрешения).
   В таблице появится лист `Заявки` с тестовой строкой, придёт сообщение в Telegram и письмо.

## 2. Публикация скрипта

1. **Начать развертывание → Новое развертывание → Тип: Веб-приложение**.
2. «Запуск от имени» — **Я**, «У кого есть доступ» — **Все**. Развернуть.
3. Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.

> После правок в `lead.gs` нужно **Управление развертываниями → Изменить → Новая версия**,
> иначе сайт продолжит работать со старым кодом. URL при этом не меняется.

## 3. Настройка страницы

В конце `landing.html`, в блоке `CONFIG`:

| Поле | Что вписать |
|---|---|
| `SCRIPT_URL` | URL из шага 2 |
| `METRIKA_ID` | номер счётчика Яндекс.Метрики (0 — не отправлять цель) |
| `ADDRESS` | адрес картодрома — по нему строится карта (сейчас ZelenoKART, ТРЦ «Зеленопарк» — проверьте) |

### Фото и видео

Фото и ролики с [Яндекс.Диска](https://disk.yandex.ru/d/CMeTPXP51OMJKg) уже сжаты и лежат в
[`media/`](media). Страница берёт их через CDN jsDelivr прямо из этого репозитория
(`MEDIA_BASE` в `CONFIG`) — загружать в Тильду ничего не нужно.

Где что используется — `CONFIG.MEDIA`: фон первого экрана (`heroVideo`), вертикальные ролики
(`reels`), фото в карточках (`features`), галерея (`gallery`), фон формы (`formBg`).
Можно указать короткое имя файла из `media/` или полную ссылку, например на картинку,
загруженную в Тильду (`https://static.tildacdn.com/...`). Длинный ролик из ВК Видео, Rutube
или YouTube — вставить ссылку в `video`.

Чтобы добавить новое фото: положите файл в `media/` (до ~1400 px по длинной стороне),
закоммитьте и поменяйте хэш коммита после `@` в `MEDIA_BASE` на новый.

> Репозиторий публичный, поэтому всё из `media/` открыто в интернете — как и на самой странице.

Ещё в HTML помечено `TODO` и нужно проверить перед запуском:
- **цены** в разделе «Стоимость» (сейчас `0 000 ₽`);
- **экипировка**: что выдаём на месте, а что берут с собой;
- карточка «Опытные тренеры» пока с иконкой — пришлите фото тренера, поставлю (`features[3]`);
- ссылка на **политику обработки персональных данных** у галочки согласия.

## 4. Тильда

1. Создайте страницу, например `/moto-zelenograd`.
2. Добавьте блок **Другое → T123 «HTML-код»**, вставьте весь `landing.html`. Сохраните, опубликуйте.
3. Шапку/подвал сайта можно поставить выше и ниже этого блока как обычно.

## 5. Яндекс.Метрика

**Метрика → Цели → Добавить цель → JavaScript-событие**, идентификатор `lead_form_submit`.
Цель срабатывает после успешной отправки формы — её можно использовать для оптимизации рекламы.

## Как проверить

Откройте страницу с `?utm_source=test`, отправьте заявку со своим телефоном — в таблице
должна появиться строка с `utm_source = test`, а в Telegram и на почте — уведомление.
