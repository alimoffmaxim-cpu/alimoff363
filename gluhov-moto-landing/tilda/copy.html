Электромото Зеленоград: блоки для Tilda

Страница в Тильде собирается из трёх блоков сверху вниз: HTML-код, стандартная форма Тильды, HTML-код. Дизайн один в один с утверждённым макетом; форма — стандартная, поэтому заявки уходят в Tilda CRM, Google Таблицу, Telegram и на почту.

1. Новая страница

  1. Мои сайты → проект → Создать новую страницу → «Пустая страница».
  2. Настройки страницы: заголовок «Электромотоциклы для детей в Зеленограде», адрес, например /moto-zelenograd.

2. Блок 1 — основная часть

  1. Все блоки → Другое → T123 «HTML-код» → «Контент».
  2. «Скопировать код» ниже → вставить целиком → «Сохранить и закрыть».

3. Блок 2 — форма Тильды BF204N

  1. Все блоки → Форма → BF204N «Вертикальная форма с множеством полей», поставить под блоком 1.
  2. Контент → Шапка блока: заголовок «Запишите ребёнка на тренировку», описание «Оставьте заявку — администратор перезвонит, подберёт группу и класс мотоцикла и ответит на все вопросы.»
  3. Контент → Поля для ввода — как в таблице; Email и прочие лишние поля удалить.
  4. Текст кнопки: «Отправить заявку →». Сообщение об успехе: «Спасибо! Администратор перезвонит вам в ближайшее время.»
  5. Контент → Приём данных: отметить Tilda CRM, Google Таблицу, Telegram и/или Email (сначала подключить их: Настройки сайта → Формы).
  6. Настройки блока: отступы сверху/снизу 0 (и для 480), ширина 12 колонок, фон #0d0f13, название формы «Электромото Зеленоград — запись», якорная ссылка signup, CSS Class Name gm-signup.

Оформление формы (тёмная карточка, жёлтая кнопка, дни-«пилюли», фото на фоне, список «Перезвоним в течение дня…») подтягивается из блока 3 по CSS-классу gm-signup. Без класса форма останется стандартной.

4. Блок 3 — подвал и скрипты

  1. Ещё один T123 «HTML-код» под формой → вставить код ниже → «Сохранить и закрыть».
  2. Опубликовать. Проверять вид только на опубликованной странице: редактор и «Предпросмотр» Тильды код T123 не выполняют.
  3. Отправить тестовую заявку «ТЕСТ» → проверить «Заявки», Tilda CRM, таблицу и Telegram → удалить тест.
