# Новый дизайн alimov.agency

Светлый минималистичный редизайн главной страницы.

| Файл | Зачем |
|---|---|
| `tilda-t123.html` | **Основной файл.** Целиком вставляется в Tilda в блок T123 «HTML-код». Все правки делайте здесь. |
| `index.html` | Та же страница как обычный HTML-файл, для предпросмотра в браузере или хостинга вне Tilda. Собирается командой `python3 site/build.py`. |
| `cases.py` | Данные кейсов: тексты, бюджеты, заявки, цели. Новый кейс добавляется сюда. |
| `cases/<адрес>.t123.html` | Страница кейса для блока T123 в Tilda. Собирается автоматически, руками не правьте. |
| `cases/<адрес>.html` | Та же страница кейса для предпросмотра в браузере. |
| `publish/` | **Готовые файлы для вставки в Tilda** (главная и пять кейсов) без черновых элементов. Как публиковать — `PUBLISH.md`. |
| `SEO.md` | Что сделано для SEO, что включить в Tilda, запросы по страницам и план продвижения. |
| `seo-meta.md` | Заголовки и описания страниц для настроек SEO в Tilda. Собирается автоматически. |
| `og/`, `icons/` | Картинки для соцсетей (1200×630) и иконки сайта. Перерисовать: `node site/make_images.js`. |
| `build.py` | Собирает `index.html` и страницы кейсов. Запуск: `python3 site/build.py`. |

## Как поставить на Tilda

1. В Tilda создайте новую пустую страницу (или скопируйте текущую главную, чтобы её не трогать).
2. В настройках страницы → «Ещё» отключите шапку и подвал, если они подключены: у страницы свои.
3. Добавьте блок **T123** («Другое» → «HTML-код»), откройте «Контент» и вставьте **всё** содержимое `tilda-t123.html`.
4. Опубликуйте страницу и проверьте её на телефоне. Когда всё готово, назначьте её главной.

## Страницы кейсов

Шаблон один на все кейсы, данные лежат в `cases.py`. Стили, меню, блок контактов и подвал берутся из `tilda-t123.html`, поэтому правки дизайна главной сразу попадают и в кейсы. После любых правок запустите `python3 site/build.py`.

На странице кейса: заголовок и паспорт проекта, тёмный блок с результатом, блок «Цель и результат» (если в кейсе есть цель по цене заявки), блоки «О клиенте», «Задача», «Что сделали» и карусель других кейсов.

Как поставить на Tilda:

1. Для каждого кейса создайте страницу с тем же адресом, что у старой: `/irbis_case`, `/genius_school`, `/tetrica_case`, `/uchi_case`, `/unicode_case` (кейс `/irbis_2324` объединён с `/irbis_case`, старую страницу перенаправьте на `/irbis_case`). Тогда ссылки с главной заработают без правок. Старую страницу перед этим переименуйте или снимите с публикации.
2. Отключите шапку и подвал Tilda, добавьте блок T123 и вставьте целиком файл `cases/<адрес>.t123.html`.
3. Заголовок и описание страницы для поисковиков задайте в настройках страницы Tilda. Готовые тексты есть в `<title>` и `description` файла `cases/<адрес>.html`.

Новый кейс: добавьте запись в `CASES` в `cases.py` и соберите страницы. Карточку на главной `build.py` добавит сам: карточки кейсов в `tilda-t123.html` стоят между метками `cases:start` и `cases:end`, руками их не правьте. Так же собираются график «Цена заявки по кейсам» (метки `chart:start` и `chart:end`) и карточка на первом экране (метки `hero:start` и `hero:end`). На первом экране по очереди показываются кейсы, у которых в `cases.py` заполнено поле `hero`: ниша из него подставляется в заголовок «Заявки для …», а карточка справа показывает цифры этого кейса.

## Что заменить перед публикацией

Элементы с атрибутом `data-draft` на странице отмечены плашкой «черновик». Замените текст и удалите `data-draft`, плашка исчезнет.

Тексты, кейсы и контакты взяты с текущего alimov.agency и страниц кейсов. Черновыми остались только данные, которых на сайте нет:

- **Вопросы:** стоимость услуг.
- **Подвал:** ИП/ООО, ИНН и ссылка на политику конфиденциальности.

Телефона и почты на текущем сайте нет, поэтому в контактах только Telegram, канал, ВКонтакте и Instagram. Если нужны телефон или почта, добавьте строки в `<dl>` блока контактов.

## Цвета и шрифты

Строгий стиль: ровный серый фон, белые карточки, чёрные блоки для главных разделов, фуксия только как акцент (ключевые цифры, полосы, выделенные слова, главная кнопка в контактах).

Цвета меняются в одном месте: в начале `<style>` в `tilda-t123.html`, в блоке `.aa { --aa-… }`. Страницы кейсов берут их оттуда же.

- Серый фон `#E6E6EA`, карточки `#FFFFFF`, линии `#D2D2D8`
- Чёрный `#0B0B0D`: текст, кнопки, блок с услугами и кейсами, контакты
- Фуксия `#E6007E` (`--aa-accent`), для мелкого текста на светлом — `#C2006A` (`--aa-accent-text`)
- Шрифты: Geologica для заголовков и цифр, Golos Text для текста. Оба с Google Fonts, кириллица поддерживается.

Фон: за светлыми блоками медленно плывут три размытых пятна (розовое, светлое и сиреневое, `.aa-blob`), поверх лежит лёгкое зерно. Фирменный мотив — мишень из тонких колец (`.aa-rings`) за карточкой на первом экране, у блока вопросов и в шапке кейса. Яркость пятен меняется в `.aa-blob--1…3`, зерна — в `opacity` у `.aa-bg::after`.

Выделить слово фуксией: `<mark class="aa-mark">слово</mark>`.

Анимации: числа с атрибутом `data-count="12652"` отсчитываются от нуля, когда появляются на экране; полосы графика растут; в тёмной части за курсором идёт розовая подсветка. Для посетителей, у которых в системе отключена анимация, всё сразу показывается в конечном виде.
