# SEO для alimov.agency

Что уже сделано в коде, что нужно включить в Tilda и что делать дальше, чтобы сайт выходил в органическую выдачу Яндекса и Google.

## 1. Что уже сделано на страницах

- **Ключевые запросы в заголовках.** H1 «Заявки для детских школ», подпись над ним «Таргетированная реклама ВКонтакте для детских школ», разделы «Таргетированная реклама ВКонтакте», «Кейсы по рекламе детских школ», «Вопросы о рекламе детских школ».
- **Текст для поисковиков.** Новый блок «Как привести заявки детской школе из ВКонтакте» (`#how`) из четырёх абзацев: реклама онлайн-школы, реклама студии с филиалами, креативы и цена заявки. Все цифры взяты из кейсов.
- **Больше вопросов.** Добавлены «Сколько стоит заявка для детской школы во ВКонтакте?», «Подходит ли таргет ВКонтакте офлайн-студии?» и «Вы работаете с моим городом?». Ответы основаны только на кейсах.
- **Разметка Schema.org (JSON-LD)**, которую читают и Яндекс, и Google:
  - на главной: организация (`ProfessionalService`), сайт, услуга, список кейсов и вопросы-ответы (`FAQPage`, только вопросы без пометки «черновик»);
  - на страницах кейсов: хлебные крошки (`BreadcrumbList`) и статья (`Article`).
- **Хлебные крошки на страницах кейсов** «Главная / Кейсы / «Тетрика»» вместо ссылки «← Все кейсы». Все кейсы ссылаются друг на друга и на главную.
- **Картинки для соцсетей и мессенджеров:** `site/og/*.png`, 1200×630, отдельная на главную и на каждый кейс.
- **Своя иконка сайта:** `site/icons/` (`favicon.ico`, `favicon.svg`, `icon-180.png` для iPhone, `icon-512.png`).
- **Скорость на телефонах:** фоновые пятна на телефоне не двигаются, размытие меньше.

Готовые заголовки и описания каждой страницы лежат в `site/seo-meta.md`. Этот файл собирается командой `python3 site/build.py`.

## 2. Обязательно включить в Tilda

Это важнее всего остального: сейчас поисковики видят несколько копий сайта.

| Проблема сейчас | Что сделать в Tilda |
|---|---|
| Сайт открывается по `http://`, `https://` и `www.`, ни один адрес не перенаправляет на основной | Настройки сайта → Домен: включить SSL (HTTPS) и перенаправление на HTTPS; основным выбрать `alimov.agency` без `www`, с `www` поставить перенаправление |
| Канонический адрес, robots.txt и карта сайта указывают на `http://` | Исправится само после включения HTTPS; потом проверить `https://alimov.agency/sitemap.xml` |
| У страницы не указан язык | Настройки сайта → Ещё → Язык сайта: русский |
| Во вкладке стандартная иконка Tilda | Настройки сайта → Иконка: загрузить `site/icons/favicon.ico` (или `icon-512.png`) |
| В карте сайта нет кейса `/genius_school` | Проверить, что в настройках страницы не стоит «Запретить индексацию», и переопубликовать её |
| Два кейса «Ирбиса» объединены в `/irbis_case` | Страницу `/irbis_2324` снять с публикации и поставить перенаправление (301) на `/irbis_case` |
| `/case_code` повторяет кейс «Учи.ру» | Снять с публикации или в настройках страницы указать перенаправление на `/uchi_case` |
| Седьмой кейс `/case_school` («заявки по 833 ₽», онлайн-репетиторы) не связан с сайтом | Решить: добавить его в `cases.py` (нужны число заявок и бюджет) или закрыть от индексации |

Для каждой страницы (главной и пяти кейсов):

1. Настройки страницы → SEO: заголовок и описание из `site/seo-meta.md`.
2. Настройки страницы → Соцсети: картинка из `site/og/`, тот же заголовок и описание.
3. Адрес страницы оставить прежним (`/genius_school`, `/tetrica_case` и т. д.), чтобы сохранить накопленный вес старых страниц.

## 3. Подключить поисковые системы

1. **Яндекс Вебмастер** (webmaster.yandex.ru): добавить `https://alimov.agency`, подтвердить через Tilda (Настройки сайта → Аналитика → Яндекс Вебмастер), указать карту сайта, в «Региональности» выбрать Россию, в «Переезде сайта» указать главное зеркало на HTTPS.
2. **Google Search Console** (search.google.com/search-console): добавить домен, подтвердить через Tilda, отправить `sitemap.xml`, запросить индексацию главной и кейсов.
3. **Яндекс Метрика** с вебвизором и целью на клики по Telegram: поведенческие факторы влияют на позиции в Яндексе, их нужно видеть.
4. После публикации проверить разметку: Яндекс Вебмастер → Инструменты → Валидатор микроразметки, Google → Rich Results Test.

## 5. Что даст рост дальше

Один лендинг с пятью кейсами занимает высокие позиции только по узким запросам. Чтобы выходить по широким, нужны отдельные страницы под каждый запрос и ссылки с других сайтов.

1. **Посадочные страницы под ниши** (самый сильный шаг): «Реклама театральной студии», «Реклама школы программирования», «Реклама онлайн-школы», «Реклама онлайн-репетитора / детского центра». На каждой: проблема ниши, подход, кейсы этой ниши, вопросы. Их можно собрать тем же `build.py` из кейсов.
2. **Статьи-кейсы на внешних площадках** со ссылкой на сайт: vc.ru, Хабр (раздел маркетинга), Сетка, тематические Telegram-каналы. Это ссылки и прямой трафик.
3. **Карточки компании:** Яндекс Бизнес (Яндекс Карты и Справочник) и Google Business Profile как компания, обслуживающая клиентов по всей России, с сайтом и Telegram.
4. **Каталоги и рейтинги агентств:** Workspace, Рейтинг Рунета, каталоги таргетологов. Это ссылки и доверие.
5. **Ссылки из своих каналов:** сайт в описании группы ВКонтакте, Telegram-канала @alimov_pro и профилей; ссылка на кейс в каждом посте о нём.
6. **Отзывы клиентов текстом** на страницах кейсов: уникальный текст и доверие. Сейчас на старых страницах отзывы только картинками.
7. **Обновление контента:** новые кейсы раз в месяц-два. Сайт, который обновляется, переобходят чаще.

## 6. Как проверять результат

- Через 2–4 недели после включения HTTPS и подключения Вебмастера: в Яндекс Вебмастере и Search Console все 6 страниц в индексе, без дублей с `http://` и `www`.
- Раз в месяц: позиции по запросам из раздела 4 (Яндекс Вебмастер → Поисковые запросы, Search Console → Эффективность).
- Органический трафик и заявки из поиска в Метрике.
