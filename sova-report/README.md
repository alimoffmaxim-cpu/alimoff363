# 🦉 Отчёт «Сова»: VK Реклама (3 кабинета) → Google Таблица

1 кабинет VK Рекламы = 1 направление клиники. В одной таблице:

| Лист | Что на нём |
|---|---|
| **🦉 Сводная** | Итог по всем направлениям: KPI месяца против тех же дней прошлого, таблица направлений с долей бюджета, расход / лиды / CPL по направлениям по месяцам и неделям, итог клиники по дням. 15 графиков |
| **Направление 1/2/3** | Итоги всех кампаний одного кабинета: KPI месяца, таблицы по месяцам (12), неделям (26) и дням (60). 9 графиков: расход, лиды и CPL по дням, неделям и месяцам |
| **⚙ Настройки** | Названия направлений (подставляются во все листы и графики) |
| **Данные** | 1 строка = 1 день одного направления: дата, направление, расход, показы, клики, лиды |

Все листы отчёта считаются **формулами из листа «Данные»**: появились новые строки,
и цифры, подсветка CPL и графики обновились сами. Отчётная дата — последний день в «Данных».

Метрики: CTR = клики / показы, CPC = расход / клики, CPL = расход / лиды,
CR в лид = лиды / клики. Неделя — с понедельника по воскресенье. «Этот месяц» — с 1-го
числа по отчётную дату, сравнение — с теми же днями прошлого месяца (▲/▼ зелёным, когда
изменение к лучшему: для CPL и CPC хорошо, когда они падают).

## 1. Таблица

1. Скачайте [`sova-report.xlsx`](sova-report.xlsx) (в ней демо-данные за год, чтобы сразу видеть, как всё выглядит).
2. Google Диск → **Создать → Загрузить файл** → откройте файл →
   **Файл → Сохранить как Google Таблицу** (скрипт работает только в Google Таблице, не в .xlsx).
3. **Файл → Настройки → Региональные настройки: Россия**, часовой пояс — Москва.
4. На листе **⚙ Настройки** впишите названия направлений в A2:A4 (например, «Стоматология»).
   Вкладки направлений переименуйте так же (двойной клик по вкладке) — формулы не сломаются.

## 2. Автозагрузка из VK (скрипт)

1. В Google Таблице: **Расширения → Apps Script**.
2. Вставьте файлы по очереди в конец `Код.gs` (код разбит на части по ≤ 100 строк, потому что
   редактор может обрезать длинную вставку): [`1_main.gs`](1_main.gs), [`2_settings.gs`](2_settings.gs),
   [`3_api.gs`](3_api.gs), [`4_sync.gs`](4_sync.gs), [`5_debug.gs`](5_debug.gs), [`6_connect.gs`](6_connect.gs). Сохраните.
3. **Настройки проекта** (шестерёнка) → часовой пояс `Europe/Moscow`.
4. Обновите страницу таблицы — появится меню **🦉 Сова**.
5. **🦉 Сова → Удалить все строки с листа «Данные»** — убрать демо-цифры.
6. Подключите каждый кабинет: **🦉 Сова → Подключить кабинет VK** → номер направления →
   `client_id` и `client_secret` из [ads.vk.com](https://ads.vk.com) → Настройки → Доступ к API
   (выдаётся по заявке в поддержку VK Рекламы). Статус появится в колонке B листа настроек.
   Запасной вариант без доступа к API: **Ввести готовый токен VK (на 24 ч)**.
7. **🦉 Сова → Загрузить новые данные из VK** — первая загрузка за 365 дней.
8. **🦉 Сова → Включить ежедневное обновление** — каждое утро около 7:00 скрипт дописывает
   вчерашний день и перезагружает последние 3 дня (VK досчитывает конверсии задним числом).
   Если один кабинет не загрузился, остальные всё равно обновятся, а Google пришлёт письмо с ошибкой.

## Настройки (`SOVA` в начале `1_main.gs`)

- `LEADS_METRIC` — какая метрика VK считается лидами (по умолчанию `base.vk.result`). Для
  отдельного кабинета её можно указать в колонке C листа настроек. Подобрать: запустите в
  редакторе `debugVkMetrics` — на лист `VK debug` выпишутся все метрики первого направления за 7 дней.
- `INITIAL_DAYS`, `REFRESH_DAYS`, `TRIGGER_HOUR` — глубина первой загрузки, сколько дней
  перезагружать, час ежедневного запуска.

## Как пересобрать шаблон

`tools/build_xlsx.py` собирает `sova-report.xlsx` (нужен `openpyxl`):
`python3 tools/build_xlsx.py sova-report.xlsx`. Число направлений в шаблоне — 3 (`DIRS`).

## Безопасность

- Репозиторий публичный: **никаких ключей в коде**. `client_id` / `client_secret` и токены
  хранятся только в Свойствах скрипта (вводятся через меню), в ошибках длинные строки маскируются.
- Права на **редактирование** таблицы — только доверенным людям (редакторы видят свойства
  скрипта). Клиенту для просмотра — доступ «Читатель».
- Утёк `client_secret` — перевыпустите его в кабинете VK и подключите кабинет заново.
