# Как получить токены для отчёта «Сова»

Отчёт «Сова» каждое утро сам забирает статистику из ваших рекламных кабинетов VK Рекламы
и обновляет Google Таблицу. Для этого нужен **токен API** — ключ, по которому отчёт
читает статистику кабинета. Ваши кабинеты ведутся через eLama, поэтому токены выдаёт eLama.

**Важно знать заранее:**
- У вас 3 кабинета, по одному на направление клиники, поэтому нужно **3 токена** — отдельно на каждый кабинет.
- eLama попросит **подтверждение с контактной почты** вашего аккаунта eLama. Проверьте,
  что у вас есть доступ к этой почте. Подтверждать нужно для каждого кабинета.
- Токен **постоянный**: получить его нужно один раз, обновлять не придётся.

## Шаг 1. Выпишите ID кабинетов

Для каждого из 3 кабинетов запишите его ID и направление клиники. ID есть в личном кабинете
eLama (список рекламных аккаунтов) или в самом кабинете VK Рекламы: **Настройки → Общие → строка «Аккаунт»**.

| Направление | ID кабинета VK Рекламы |
|---|---|
| Направление 1: ________ | ________ |
| Направление 2: ________ | ________ |
| Направление 3: ________ | ________ |

## Шаг 2. Запросите токены в eLama

Напишите в поддержку eLama: в чат в личном кабинете eLama или на **milo@elama.ru**.
Текст можно скопировать:

> Здравствуйте! Прошу выдать постоянные токены API VK Рекламы для выгрузки статистики
> в отчёт (нужно только чтение статистики). Токен нужен отдельно для каждого кабинета:
> 1. ID ________
> 2. ID ________
> 3. ID ________
>
> Мой аккаунт в eLama: ________ (почта / логин).

## Шаг 3. Подтвердите запрос с почты

На контактную почту аккаунта eLama придут письма для подтверждения, обычно отдельное на каждый кабинет.
**Подтвердите каждое.** Если письма нет, проверьте папку «Спам», а если и там нет — напишите в поддержку eLama.

## Шаг 4. Передайте токены нам

Когда eLama пришлёт токены:
1. Подпишите каждый токен: **какой кабинет / какое направление**.
2. Отправьте их **лично вашему специалисту**, не в общий чат. Удобнее всего каждым токеном отдельным сообщением.
3. После того как специалист подтвердит, что подключил отчёт, сообщения с токенами можно удалить.

Дальше всё сделаем сами: подключим кабинеты к таблице, и отчёт начнёт обновляться каждое утро.

## Безопасность

- Токен даёт доступ к статистике кабинета. Не публикуйте его и не пересылайте посторонним.
- Если токен попал не туда, попросите eLama отозвать его и выдать новый.
- Ограничить доступ можно в любой момент: попросите eLama отозвать токены, и отчёт перестанет получать данные.
