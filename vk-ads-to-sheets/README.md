# Выгрузка статистики VK Реклама → Google Таблица

Скрипт Google Apps Script живёт прямо внутри таблицы, раз в сутки забирает
статистику из [ads.vk.com](https://ads.vk.com) и записывает её на лист `VK Ads`.
Сервер не нужен.

## 1. Доступ к API VK Реклама

1. ads.vk.com → **Настройки → Доступ к API** → запросить доступ (VK одобряет заявку вручную).
2. После одобрения там появятся **client_id** и **client_secret**. Их никуда
   не копируйте, кроме шага 3.

## 2. Скрипт в таблице

1. Создайте Google Таблицу → **Расширения → Apps Script**.
2. Вставьте содержимое файла [`Code.gs`](Code.gs) вместо шаблонного кода, сохраните.
3. Слева **Настройки проекта** (шестерёнка) → внизу **Свойства скрипта** → добавьте:
   | Свойство | Значение |
   |---|---|
   | `VK_CLIENT_ID` | ваш client_id |
   | `VK_CLIENT_SECRET` | ваш client_secret |
4. Там же проверьте **часовой пояс** (например, `Europe/Moscow`).

## 3. Первый запуск

1. В редакторе выберите функцию `exportVkAdsStats` → **Выполнить**, дайте разрешения.
2. Для истории выполните `backfill90Days`.
3. Выполните `setupDailyTrigger` — дальше обновление идёт каждый день само
   (около 7:00, меняется в `CONFIG.TRIGGER_HOUR`).

После перезагрузки таблицы появится меню **VK Реклама** с теми же действиями.

## Настройки (`CONFIG` в начале `Code.gs`)

- `LEVEL` — `ad_plans` (кампании), `campaigns` (группы объявлений), `banners` (объявления).
- `DAYS_BACK` — сколько последних дней перезаписывается при каждом запуске
  (VK пересчитывает статистику задним числом). Более старые строки не трогаются.

Если появится ошибка о лимите токенов — выполните `deleteAllVkTokens` и запустите выгрузку снова.

## Безопасность: как не опубликовать ключи на GitHub

Этот репозиторий **публичный** — всё, что в него попало, видно всем (и остаётся в истории коммитов даже после удаления файла).

- **Секреты хранятся только в «Свойствах скрипта»** Apps Script, а не в коде.
  В `Code.gs` нет ни client_id, ни client_secret, ни токенов — его можно спокойно коммитить.
- **Никогда не вставляйте ключи в код «на время»**: при следующем копировании
  кода в репозиторий они уйдут в публичный доступ.
- `.gitignore` в корне не даёт закоммитить типичные файлы с секретами
  (`.env`, `credentials*.json`, `.clasprc.json` и т. п.) — секреты, если нужно
  хранить локально, кладите только в такие файлы.
- На GitHub: **Settings → Code security → Secret scanning / Push protection** —
  держите включёнными, GitHub заблокирует push с распознанным ключом.
- Доступ на **редактирование** таблицы давайте только доверенным людям: редакторы
  видят свойства скрипта. Для просмотра данных делитесь с правом «Читатель».
- **Если ключ всё-таки утёк** (попал в коммит, чат, скриншот) — удаления из репозитория
  недостаточно: перевыпустите client_secret в ads.vk.com (Доступ к API),
  выполните `deleteAllVkTokens` и обновите `VK_CLIENT_SECRET` в свойствах скрипта.
