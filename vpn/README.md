# Семейный VPN для Happ

Свой VPN-сервер на 2–5 человек. Протокол **VLESS + Reality**: для провайдера трафик выглядит как обычное
HTTPS-соединение с крупным сайтом (по умолчанию `www.microsoft.com`), поэтому его сложно отличить и заблокировать.
Домен и сертификаты не нужны. Клиент — **Happ** (iPhone, Android, Windows, macOS).

Время установки — около 10 минут. Стоимость — только сервер, примерно 4–6 $ в месяц.

---

## 1. Арендуйте сервер (VPS)

Подойдёт самый простой тариф: **1 vCPU, 1 ГБ RAM, Ubuntu 24.04 или Debian 12**, страна — **Нидерланды,
Финляндия, Германия или Швеция** (близко к России = низкий пинг).

Советы по выбору хостера:
- Хостеры, принимающие российские карты или СБП: например PQ.hosting, 4VPS, VDSina, Hostkey, Timeweb Cloud
  (берите **зарубежную** локацию). Остальные — оплата криптой.
- У самых популярных хостеров (Hetzner, DigitalOcean, OVH, часть AWS) диапазоны IP в России иногда «душат»:
  соединение открывается, но через пару секунд зависает. Если увидите такое — смените хостера или попросите
  новый IP. Ситуация меняется, поэтому лучше брать посуточную/помесячную оплату, а не на год.
- Перед покупкой можно проверить IP: зайдите на сайт хостера из России без VPN — если тестовый файл
  (looking glass / speedtest) качается нормально, это хороший знак.

После оплаты хостер пришлёт **IP-адрес и пароль root**.

## 2. Установите VPN на сервер

Подключитесь к серверу по SSH:
- с компьютера: `ssh root@ВАШ_IP` (Windows — в PowerShell или PuTTY),
- с телефона: приложение **Termius**.

Затем скопируйте файл `vpn.sh` на сервер. Проще всего — создать его через редактор:

```bash
nano vpn.sh        # вставьте содержимое vpn.sh, затем Ctrl+O, Enter, Ctrl+X
```

Или, если репозиторий публичный, скачать одной командой:

```bash
curl -fsSLo vpn.sh https://raw.githubusercontent.com/alimoffmaxim-cpu/alimoff363/main/vpn/vpn.sh
```

Запустите установку, перечислив членов семьи (латиницей или кириллицей, без пробелов):

```bash
bash vpn.sh install мама папа я
```

Скрипт сам: поставит Xray, сгенерирует ключи, создаст по отдельной ссылке на каждого человека, включит
файрвол (открыты только SSH и 443) и ускорение BBR. В конце для каждого человека будет показана
**ссылка `vless://...` и QR-код**. Ссылки также лежат в `/root/vpn-clients/`.

## 3. Подключите телефоны и компьютеры (Happ)

1. Установите **Happ**:
   - iPhone/iPad — App Store (в российском App Store приложения может не быть — понадобится
     Apple ID другой страны);
   - Android — Google Play или APK с сайта happ.su;
   - Windows/macOS — с сайта happ.su.
2. Отправьте человеку **его** ссылку (например, в мессенджере) и скопируйте её на устройстве,
   либо отсканируйте QR-код с экрана.
3. В Happ нажмите **«+» → «Вставить из буфера»** (или «Сканировать QR»).
4. Нажмите большую кнопку подключения. Разрешите добавление VPN-конфигурации.

Рекомендация: в настройках Happ включите **маршрутизацию «Россия напрямую»** (российские сайты мимо VPN),
если она есть в вашей версии. Тогда банки, Госуслуги, маркетплейсы работают как обычно, а VPN
используется только для зарубежных сайтов.

## 4. Управление

После установки на сервере доступна команда `vpn`:

| Команда | Что делает |
|---|---|
| `vpn add бабушка` | добавить человека (покажет ссылку и QR) |
| `vpn remove папа` | отключить человека — его ссылка перестанет работать |
| `vpn list` | список людей |
| `vpn show мама` | снова показать ссылку и QR (`vpn show` — всех) |
| `vpn sni www.example.com` | сменить сайт для маскировки (ссылки обновятся у всех) |
| `vpn update` | обновить Xray до последней версии |
| `vpn status` | состояние сервера |

Раз в 1–2 месяца выполняйте `vpn update` и `apt update && apt upgrade -y`.

## 5. Если перестало работать

Пробуйте по порядку:

1. **Проверьте сервер:** `vpn status` — должно быть `active (running)`. Если нет — `vpn restart`.
2. **Смените сайт маскировки.** Подходят крупные зарубежные сайты с TLS 1.3, не заблокированные в РФ:
   `vpn sni www.microsoft.com`, `vpn sni dl.google.com`, `vpn sni www.samsung.com`,
   `vpn sni www.nvidia.com`, `vpn sni addons.mozilla.org`. Лучше всего — сайт, который хостится
   в том же дата-центре/стране, что и ваш сервер. После смены заново добавьте ссылки в Happ.
3. **Смените IP** (у хостера — «заказать новый IP» или пересоздать сервер) и выполните
   `bash vpn.sh install ...` на новом сервере.
4. **Мобильный интернет и «белые списки».** В некоторых регионах при отключениях мобильного интернета
   работают только разрешённые российские сайты — тогда **никакой** зарубежный VPN не подключится.
   Используйте Wi-Fi/домашний интернет. Обойти это можно только каскадом через российский сервер
   (продвинутый вариант, этот скрипт его не настраивает).

## Безопасность

- Не пересылайте ссылки за пределы семьи: кто имеет ссылку — пользуется вашим сервером.
- Скрипт блокирует торренты через VPN (хостеры закрывают серверы за жалобы правообладателей)
  и доступ к локальной сети сервера.
- Ключи хранятся на сервере в `/usr/local/etc/xray/` — их не нужно никуда копировать.

## Для разработчика: тест без сервера

```bash
SKIP_SYSTEM=1 XRAY_DIR=/tmp/vpn/etc CLIENTS_DIR=/tmp/vpn/clients \
XRAY_BIN=./xray SERVER_IP=203.0.113.5 bash vpn.sh install мама папа
```

`SKIP_SYSTEM=1` пропускает apt/systemd/ufw; конфиг проверяется через `xray run -test`.
